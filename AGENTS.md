# RealmStatus

- Перед изменениями прочитайте [архитектуру](docs/architecture.md) и проследите затронутый путь от точки входа до внешнего сервиса.
- Добавляйте источники онлайна через `StatusSource`. Статус «недоступен» и нулевой онлайн различаются.
- Задавайте список игр, выбранные источники и пути управления в TOML. Параметры выключенных игр и невыбранных источников не должны мешать запуску.
- Держите проверку чата и ID пользователя на границе Telegram. Управляющие команды берут имена Make-целей только из локальной конфигурации.
- Сохраняйте старый облачный обработчик и интеграции Realms и Stardew Valley. Новый процесс не должен запускать старый цикл публикации.
- Храните токены и сессии локально. Используйте `make preview` для проверки без записи в Telegram.
